# Translations

[← Back to the README](../README.md)

Kestrel Explorer is translated into Chinese (Simplified), French, German, Italian, Japanese, Korean, Portuguese
(Brazil and Portugal), Russian and Spanish. It uses your desktop's language, and English where it has no translation.

These translations are new and haven't been checked by native speakers yet, so some texts may be wrong, unclear or
awkward. If you find one, please report it with the
[Incorrect translation](https://github.com/RegulusArms/kes-c/issues/new?template=incorrect_translation.yml) form in
the issue tracker.
