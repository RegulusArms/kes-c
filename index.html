Kestrel Explorer

apt repository for Ubuntu 24.04 / Linux Mint 22 and newer (amd64). Source: github.com/RegulusArms/kes-c

Install

sudo install -d -m 755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/kestrel.asc https://regulusarms.github.io/kes-c/kestrel.asc
sudo tee /etc/apt/sources.list.d/kestrel.sources >/dev/null <<'EOF'
Types: deb
URIs: https://regulusarms.github.io/kes-c
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/kestrel.asc
EOF
sudo apt update && sudo apt install kestrel-explorer

Then run kes, or open Kestrel Explorer from the app menu.

Development builds

For the latest build of the DEV branch instead, use Suites: dev in /etc/apt/sources.list.d/kestrel.sources, then sudo apt update && sudo apt upgrade.

Remove

sudo apt remove kestrel-explorer
sudo rm /etc/apt/sources.list.d/kestrel.sources /etc/apt/keyrings/kestrel.asc
